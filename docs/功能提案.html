下一批指令与新功能：
让手更省事，让 AI 更笃定

基于真实工作习惯与既有交互范式（校对符号 / 白板笔势 / 页面缩略图 / 块编辑器），提出 9 个新指令、意图回显系统、多页面排版完整方案与提示词架构。每个指令都配有与产品「功能说明书」同款的动画。

00一页摘要

你要的两个问题，答案各是一句话：

要加什么指令？ 把「校对符号」搬进来：划掉＝删除、圈＋箭头＝移动、虚线＝分页、大圈＋旁写＝成节、空框＋字＝插图占位、圈＋？＝提问。这些符号人类已经在纸面上用了一百年（ISO 5776 校对符号标准），不需要学习。
第二页内容怎么移到第一页？ 用户视角：圈住那段文字，箭头直接拖到左侧页面缩略图栏的「第 1 页」上，松手出现意图条「把这段移到第 1 页顶部」，点「排一版」生效。系统视角：LaTeX 里没有"页"只有"流"，所以底层执行的不是"移动内容到某页"，而是把该段落的源码块搬移到目标页首个块之前，重新编译让"页"重新长出来。页是输出，块才是操作对象。

01六条设计原则（每条都有出处）

所有指令设计从这六条推出。前三条管「用户好不好画」，后三条管「AI 好不好懂」。

① 沿用百年行规，零学习成本

校对行业有国际标准符号（ISO 5776:2022，16 个核心符号；英式 BS 5261-2 更全）：删除＝划线、插入＝^、调位＝圈。学生改论文时在打印稿上就是这么画的。用行规做手势，用户第一次就会用。

② 一墨一意，绝不猜二义

每一组笔迹只产生一个意图。宁可让用户多画一次，也不让系统猜"你可能是想……"。歧义交给下面的「意图回显」让用户自己确认，而不是让 AI 拍板。

③ 借成熟软件的心智模型

页面缩略图栏＋拖拽排序是 PDF Expert / InDesign / macOS Preview 二十年来的标准；块拖拽手柄是 Notion 确立的标准。用户在这些软件里练出来的肌肉记忆直接可用。

④ 几何拿结构，模型拿语义

笔迹坐标、文字层、源码定位全部由几何/程序完成（可测试、可复现）；AI 只负责模型才擅长的事：读手写标签、判断块语义、消歧。AI 永远不发明坐标、不改措辞。

⑤ 先回显，后执行

画完不出结果，先出「意图条」：一句人话总结将发生什么。用户确认后「排一版」才执行。 ambiguous 的输入在这里被拦下，AI 拿到的是确认过的干净意图。（Nielsen 可用性准则 #3 用户控制、#9 防错）

⑥ 页是影子，块是身体

LaTeX 的页是排版结果不是容器。所有跨页操作的底层都是块操作＋重排版；界面上的"页"只是块模型的投影。想清楚这一点，多页面问题就从"不可能"变成"顺理成章"。

02交互模型：意图回显系统（先做这个）

这是所有新指令的公共底座，优先级高于任何单个手势。画完一条，右下立即浮出「意图条」——一句人话说明将发生什么；点「排一版」时执行的是这些确认过的意图，而不是让 AI 猜截图。

意图条（Intent chips）P0 · 底座

用户侧
每确认一条指令（右键 / Ctrl+滚轮），画布边侧浮出一条意图：「① 加粗：Drawing is faster.」。点意图条高亮对应笔迹；划掉意图条＝撤销这一条。「排一版」按钮实时显示待执行条数。
AI 侧
发给模型的不再是"截图请你理解"，而是几何（笔迹框）＋编号文字层＋确认过的意图草案。模型只做两件事：把意图条的文字抄准（逐字引用 [Lnn] 行）、标记置信度。看不懂时意图条直接显示「红笔这条没看懂——点此看猜测」，猜错率变成可见、可纠正的东西。
为什么先做它
它同时解决三个问题：用户对"AI 到底理解了什么"从黑盒变透明；二义笔迹在被执行前被拦截；提示词从"理解整张图"降级为"核对已结构化的意图"，出错率断崖式下降。

03指令词汇表（9 个，按优先级）

每个指令四栏：怎么画（用户习惯依据）→ 系统怎么懂（几何/AI 分工）→ 边界情况 → 验收标准。动画循环播放，最终帧即完整效果。

G1 · 划掉删除 P0当前稿 / 多页

怎么画
在要删的段落/图上画一条或几条横线（涂掉）。这是校对符号里的标准「删除」记号，不需要学习——每个改过打印稿的人都这么干。整体删＝一条粗划线穿过整段；只删一句＝短划线只压那句。
系统怎么懂
几何为主：划线笔迹的包围盒与文字层各词框求交，覆盖率 ≥50% 的连续行块即为目标——这一步不需要 AI。AI 只在两种情况介入：目标块是否连带
标题（整节删除）、以及部分删除时从编号行里挑出确切句子。执行器直接删除源码中对应块（含环境包裹），完全不经过模型改写。
边界
划到一半犹豫停笔＝短划线，只删被压住的那几句（意图条会写明删哪几句）；划线穿过两个块＝拆成两条意图，各自回显。
验收
① 划一段→意图条文字与段落逐字一致；② 排一版后该段源码被整块移除、其余内容零改动（diff 校验）；③ 误触划线点 × 即消失。

G2 · 页内移动 P0复用现有箭头

怎么画
圈住要挪的块，箭头指向目标位置——指向两块之间的空隙表示"插到这里"，指向某块表示"放到它后面"。这与现有画版的「圈＋箭头＋框」同源，用户已会。
系统怎么懂
几何层做两件事：把圈住的词聚成块（文字层按行/段聚类）；把箭头终点对齐到最近的块间隙（文字层的行间空隙带，宽 ≥ 12pt 才算合法落点，落点吸附防抖）。意图条写「『B』移到『C』之后」。执行器在源码里把 B 的源码区间整体搬到 C 之后，其余零改动。
边界
箭头落点不在任何间隙附近＝意图条提示「箭头没指向空隙，请指到两段之间」；移动的是 § 标题＝意图条追问「连小节一起移吗？」。
验收
① 空隙吸附半径 ≥15pt，错 3mm 内仍吸附；② 执行后除被移块外其余段落源码逐字节不变；③ 浮动图（figure）移动后给出「图是浮动体，落点受 [htbp] 影响」的提示而非假装精确。

G3 · 跨页移动（第二页 → 第一页）P0需要页面缩略图栏

怎么画（你问的场景）
翻到第 2 页，圈住「实验设置」那段，箭头往左拖出页面，落点在页面缩略图栏的「第 1 页」缩略图上。缩略图闪蓝、顶部出现插入条，松手即出意图条：「移到第 1 页 · 顶部」。想放到第 1 页某段之后？落点指到缩略图里对应的行之间即可（缩略图本身就是块的投影）。
系统怎么懂（底层三步）
① 源定位：圈住的词通过文字层 + SyncTeX（Tectonic 支持 --synctex，能给出 PDF 坐标 ↔ 源码行列的精确映射）定位到源码中该段的字符区间；② 块搬运：执行器把这段源码剪切、粘贴到目标锚点之前——目标锚点 = "第 1 页第一个文本行"对应的源码块；③ 重排版：重新编译，让"页"重新长出来。全程无模型参与，所以零措辞风险。AI 只在源定位有歧义（同名短语多处出现）时被叫来做选择题：给出候选块列表让它挑编号，而不是让它生成。
边界
移动会推挤后面所有内容——意图条写清「第 2 页起内容将顺延」，这是排版流的本性，不藏不装；跨页移动在画版模式仍禁用（画版＝单页自由版面，两个心智模型不混）。
验收
① 圈+箭头到缩略图→意图条目标正确；② 执行后该段出现在第 1 页顶部、其余内容零措辞改动（diff 只有一处搬移）；③ 歧义短语触发候选选择而非静默猜。

G4 · 适配框（移动＋缩放统一）P1画版语法升级

怎么画
圈住图/表/段落，箭头拉到一个目标框——内容按框适配：框更小就缩字号/缩图，框更大就放大，原尺寸放得下就保持。把画版模式里已验证的「矩形＋箭头＋同色目标框」语法升级回当前稿模式，一套语法覆盖搬移、缩放、跨栏摆放三种需求，用户少学一条指令。
系统怎么懂
意图 kind 复用 place，新增 fit_policy: keep|shrink|grow|exact。几何层出源框与目标框；执行器按策略改 \includegraphics[width=…] 或字号/行距；Pro 只在「框内如何断行更好看」这种审美层介入，且接受自检＋确定性兜底（现有管线原样复用）。
边界
目标框比例与原图差异过大时意图条提示「将裁剪/留白」；表格不缩字号（会破坏可读性），改为提示缩列宽。
验收
① 圈小图＋大框→图放大且清晰度参数同步改；② 同尺寸框→零改动并在意图条注明「原尺寸已适配」；③ 框在另一栏→内容跨栏且页内其他元素不动。

G5 · 分页线 P1

怎么画
用蓝笔在页面上画一条横贯页宽的虚线（虚线＝逻辑切分，与黑笔实线＝视觉装饰线天然区分）。或在页面缩略图右键菜单选「在此处分页」。
系统怎么懂
几何判定：线段水平度（±5°）、长度 ≥ 70% 页宽、虚线笔迹（多点间歇特征）。执行器在最近块边界插入 \newpage——注意用 \newpage 而非 \clearpage：前者只分页不冲掉浮动体，行为最接近用户的纸面直觉。意图条写「在此处分页（其后内容移到下页）」。
边界
位置落在段落中间＝吸附到最近段界并在意图条注明；已有显式分页的附近再画＝提示已存在而非重复插入。
验收
① 虚线处出现分页且点实线（黑笔）不触发；② 撤销意图条即移除 \newpage；③ 段中间画线吸附到段界。

G6 · 分组成节 P2

怎么画
用一个大圈把几块零散内容圈在一起，在圈旁手写（或备注栏输入）节名，比如「方法」。对应你最初愿景里"这三段是一组、整理成报告"的场景。
系统怎么懂
几何出圈住的行块列表；AI 干唯一擅长的事：读手写标签（视觉模型）＋确认这些块适合组成一节。执行器在源码中给这些块包上 \section{方法}（层级由现有标题结构推断）。没写标签时，AI 给出三个从内容提炼的候选节名放进意图条供点选——生成候选而不是替用户定夺。
边界
圈内含已有节标题＝提示层级冲突并建议子节；圈跨页＝拆成跨页分组意图（P3 再支持，先拦下说明）。
验收
① 圈＋手写「方法」→ \section{方法} 正确包裹且原文字零改动；② 无标签→出现三个候选节名；③ 层级自动匹配（已有 \section 时用 \subsection）。

G7 · 旁注约束 P2

怎么画
在页边空白处写短约束词（两栏 / 字号小一档 / 行距 1.5 / 放右），画一条小连线拴到目标块。和右下角备注栏的区别：备注栏约束整条指令，旁注只约束拴住的那一块——空间绑定，谁的约束谁领走。
系统怎么懂
连线终点确定归属块（几何）；视觉模型读手写词并与约束枚举表匹配：两栏/单栏、字号±1、行距数值、对齐方式、留白。枚举表外的词不硬猜——意图条显示「旁注『宋体』：已识别，但该约束属于整条指令，已帮你写进备注栏」。AI 的输出被枚举表收窄，理解错误率天然下降。
边界
没画连线＝按就近块归属并在意图条写明；约束互相冲突（同块两栏＋字号放大放不下）＝意图条提示冲突让用户取舍。
验收
① 手写「两栏」→ 该段以 multicol/paracol 双栏且仅该段；② 无法识别的字迹→诚实报错并建议改用备注栏；③ 枚举外词汇路由到备注而非硬执行。

G8 · 插入占位 P1

怎么画
用矩形工具拖一个空框，在框里写一个字：图 / 表 / 目录 / 公式。这是"我知道这里该有张图，回头再补"的真实工作流——先占位，不打断写作。
系统怎么懂
空矩形（无文字层命中）＋框内单字标签 → 插入对应占位环境：figure（含 caption 槽与 [htbp]）、table（三线表骨架）、\tableofcontents。AI 的活：根据上下文给 caption 草稿（放进意图条，点接受才写入）。微软研究院的 SpaceInk（UIST 2019）研究过同一个问题：在文档里"腾出书写空间"——我们用占位框回答它。
边界
框画在两段之间＝浮动体就近锚定并提示可能漂移；写「图」但框比例竖长＝提示竖版画幅。
验收
① 空框＋「图」→ 编译出带占位区的 figure 且 caption 草稿在意图条里；② 占位后正文引用「如右图所示」高亮提示可挂 \ref；③ 删除占位＝G1 划掉即可。

G9 · 页面栏操作（重排 / 删页）P1依赖页面栏

怎么操作
拖缩略图排序、插入条指明落点（Preview / InDesign 二十年惯例）；缩略图右键＝分页 / 删页。删页是危险操作：因为页是流，删页＝删除该页全部块——意图条必须列出将被删的块清单并要求点二次确认。
系统怎么懂
缩略图顺序即块顺序的投影：拖拽重排 = 交换源码中对应块的顺序（以显式 \newpage 为界；无显式分页时以顶层块为单位）。这里再次体现「页是影子」：重排页其实是重排块，重编译后页自然跟上。
边界
无显式分页的文档里"整页重排"可能引起内容跨页流动——意图条明确写「按块重排，分页位置可能移动」；删空页（无内容）＝只删分页符。
验收
① 拖拽出现插入条且松手后缩略图顺序更新；② 删页出现块清单＋二次确认；③ 所有页面操作可整体打回。

G10 · 圈选问询 P2信任功能

怎么画
圈住任何内容，在旁写一个 ？。不产生任何修改——意图条变成解释条：「这是 §2.1 实验方法（2 段）；可以：移动 / 删除 / 成节」。它同时是新手的教学工具和系统自我坦白的窗口：AI 把它理解成什么直接告诉你，理解错了你立刻知道。
系统怎么懂
问号手势路由到"只读"分支：复用源定位给出块身份，绝不触发执行器。成本几乎为零，收益是对系统的信任。（对应「给用户解释系统将做什么」这条 AI 产品的责任原则。）

04多页面排版：完整方案

你的核心问题「第二页内容移到第一页怎么办」拆成三层回答：用户怎么操作（上面 G3 已演示）、界面长什么样（页面栏）、底层怎么做（块模型）。最后是提示词怎么写。

4.1 页面栏：多页面的家

左侧常驻一条页面缩略图栏（可折叠）：当前页高亮、点击跳页、拖拽排序、右键分页/删页。它同时是跨页箭头的落点靶子。这是 PDF 编辑器二十年的标准位置，用户不用想就知道去那找"页"。

关键认识：在 LaTeX 里页面栏不是"页的容器"，而是"块的投影"。每一页显示的是"落在这一页上的块"。用户拖页、删页、跨页移动，系统翻译成块操作——因为只有块才是 LaTeX 里真实存在的东西。界面说页的话，底层做块的事，这就是整个多页面方案的枢纽。

4.2 底层架构：块模型（新增 texmap 模块）

源码 (main.tex)                块模型 (texmap.py)               界面投影
┌─────────────────┐   解析    ┌──────────────────────┐   映射   ┌──────────────┐
│ \section{引言}   │ ───────→ │ Block{kind:section,   │ ──────→ │ 页面栏：每页   │
│ 引言的正文……     │  synctex  │  src:[L12-L30],       │  渲染页  │ 有哪些块      │

三个要点：

SyncTeX 是精确映射的钥匙

Tectonic 支持 synctex：编译时生成 .synctex 文件，记录 PDF 上每个字与源码行列的对应。圈住的词 → 查 synctex → 精确源码区间。不再依赖字符串模糊匹配（模糊匹配降级为兜底）。

执行器只做四种块操作

move_block / delete_block / wrap_section / insert_newpage——全部是源码区间的剪切粘贴，全部可单测、可 diff 验证"其余零改动"。模型永远不直接产出源码（compose 自由排版除外，且已有自检+兜底）。

多页截图策略

视觉模型一次只看一页主截图（现状）；跨页意图时追加目标页小缩略图拼进截图（标注 THUMB）。不给整份文档截图——token 贵、注意力散，且模型不需要看全部内容就能完成意图核对。

编译后回填页码

执行块操作→重编译→从 synctex 读回每个块现在落在第几页→更新缩略图与意图条的页码引用。用户看到的页码永远是刚编译完的真实页码。

4.3 跨页移动的完整时序（底层视角）

1. 用户在第 2 页圈住段落 P，箭头拖到页面栏「第 1 页」缩略图上        ← 纯前端几何
2. 意图入列：{kind:"move_block", src_page:2, dst_page:1, dst_pos:"top"}
3. 点「排一版」→ resolve 阶段：
   a. P 的词框 --synctex--> 源码区间 [char_start, char_end]         ← 确定性
   b. 目标锚点 = 第 1 页首个文本行 --synctex--> 源码位置             ← 确定性
   c. 若 P 短语在全文多处命中 → 让 Pro 做选择题（给候选编号）        ← 唯一动模型的点
4. execute 阶段：源码剪切粘贴（连同所属环境整体搬运）               ← 确定性
5. 编译 → 失败则走现有 repair 循环（最多 2 次）
6. synctex 回读新分页 → 缩略图更新 → 用户收下/打回                  ← 现有循环

05提示词架构：怎么写才能让 AI 稳定执行

总纲一句话：让模型的每一步输出都是"选择题或抄写题"，绝不让它做"证明题"。坐标来自笔迹、措辞来自文字层、结构操作来自执行器——模型只填语义空格。

5.1 感知层提示词（每条指令一个模板）

# perceive_move —— 识别"圈+箭头"意图（视觉模型，一次一页）
You see one PDF page. Ink is the user's overlay. The numbered text layer
([Lnn]) is below.
A MOVE intent = one colored loop around a text block + an arrow.
The arrow target is described by geometry we already computed (see
arrow_target below) — do NOT guess coordinates.

Return JSON only:
{
  "kind": "move_block",
  "source_text": "«quote CHARACTER-FOR-CHARACTER from [Lnn] lines»",
  "confidence": "high" | "low"
}

Rules:
R1. source_text must be copied character-for-character from the
    numbered lines. Never paraphrase. Never join lines creatively.
R2. If the loop covers multiple paragraphs, set confidence=low.
R3. If no loop+arrow pair exists, return {"kind":"none"}.

5.2 消歧提示词（只在源定位有歧义时调用，是选择题不是证明题）

# disambiguate —— Pro 模型，给候选挑编号
The phrase "实验设置：本文采用" appears in N candidate blocks:
1. §2 实验设置 (src L40-L58, currently page 2)
2. §4 实验设置补充 (src L112-L119, currently page 4)
User selected the one near page-2 top. Return JSON {"block": 1}.
Do not explain. Do not output anything else.

5.3 五条硬规则（写进每类提示词的 R1-R5）

规则为什么
R1 逐字引用：文字一律从编号文字层抄，禁止转述转述是措辞漂移的唯一来源；抄写题的正确率远高于证明题
R2 坐标禁造：几何只来自笔迹数据，模型不许输出坐标模型没有空间计算能力，输出坐标必然幻觉
R3 枚举收窄：kind、约束词、fit_policy 全部用枚举表自由文本的输出空间无限大，枚举把错误率压到可测
R4 自检字段：返回前自填 checks，false 触发确定性兜底让模型自己承认失败，好过让它硬编一个错的结果
R5 置信度必填：low 置信度不执行，转成问询/候选给用户不确定就上抛，永远好过静默出错

5.4 失败 taxonomy（每种失败都有明确的接盘者）

几何失败（笔迹不构成任何已知手势）

意图条：「这条没看懂」。给最接近的两个猜测点选。不调用模型，省钱省时。

定位失败（文字层找不到引用块）

模糊匹配兜底（现有的 longest_span 思路）；仍失败→意图条请用户圈准一点。不调用模型。

语义失败（多处命中/手写不认识）

消歧选择题（Pro）或诚实报错。模型的输出被候选列表约束。

编译失败

现有 repair 循环（日志回喂，最多 2 次）。这是唯一让模型碰完整源码的地方，且只许"最小修复"。

06配套功能（按用户工作流推出来）

功能工作习惯依据设计要点优先级
意图历史（时间线）写报告是迭代过程，常想"退回上午那版"已有 data/history 备份，补一个「历史」面板：每次收下存一帧，缩略图浏览、一键恢复。已有底层，只差 UIP0
块大纲面板长文档靠标题导航；结构级调整在大纲里比画布快章节树列表：点击跳页、拖拽排序（= G2 的结构通路）。同一块模型，两种视图P2
导出 .tex / 比对视图报告常要交 LaTeX 源或看改动导出当前源码；收下前可展开"这次改了什么"（意图条列表即 diff 摘要）P1
模板起步目标用户的第一障碍是"空白文档"内置课程报告 / UROP 报告 / 简历 / proposal 四个骨架 .tex，选模板→直接进入画画P1

07路线图建议

排序依据：先做「让每次生成更可控」的（意图条），再做「扩大词汇量」的（新手势），最后做「长期资产」的（块模型+页面栏）。每档做完都独立可用、可测试、可上 GitHub。

批次内容为什么先做
P0 · 可控性意图回显条、划掉删除、页面缩略图栏、跨页移动（G3）、历史面板、PDF/文本导入意图条是所有后续指令的底座；跨页移动是你点名要的场景；导入解决"谁来用"
P1 · 词汇量适配框统一（G4）、分页线（G5）、插入占位（G8）、页面栏右键操作（G9）、导出 .tex、模板起步扩大手势覆盖面，每个都小而独立
P2 · 结构力分组成节（G6）、旁注约束（G7）、块大纲、圈选问询（G10）、偏好学习依赖块模型成熟；对应"零散内容整理成报告"的原始愿景
P3 · 生态iPad / Apple Pencil（约 Defeat 一下笔锋、防误触）、多人文档、LaTeX 工程目录（多文件/图/bib）交互范式验证成功后再放大
验证优先：路线图每一步都应先在 5–10 个真实同学身上验证（给同一份任务稿，量时间、问"下次还用吗"），再投入下一批。P0 做完就是一个值得拿去测的版本。
