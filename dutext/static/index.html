功能说明

你来画，我来排版 —— 每种笔迹就是一条指令。

画笔迹→排一版→收下 / 打回 「画版」是单页自由排版；彩色指令一次最多三条（红 → 黄 → 蓝），黑笔不限。

圈选加粗 当前稿

用「圈选」画一个椭圆圈住一句话，再在旁边画一个感叹号——那句话就会加粗。系统会优先精确识别这个标准画法，不用等模型。

确认一条指令 当前稿

画完一条后右键或 Ctrl+滚轮确认，自动换下一种颜色；普通滚轮用来滚动页面。确认过的笔迹就是一条完整指令，最多三条。

画版 · 挪文字 画版

顶栏「画版」进入单页排版：用矩形圈住左边要挪的段落，箭头拉到右边，再画一个同色目标框——AI 会把文字排进框里，放不下就自动调字号行距，放得下就保持原字号。

黑笔 · 版面模板 画版

黑笔画什么算什么：实线、框、表格线都按你画的位置来。画不直的帮你拉直，间距不匀的帮你调匀，不会被合并成一整块装饰。黑笔可选，不画就不加。

收下与打回 通用

「排一版」之后右边是提案：满意点收下，它成为新的当前稿（收下前自动留备份）；不满意点打回，笔迹保留，改完再排一次。

先在 ⋯ 菜单里保存 API Key。红黄蓝各算一条指令；右键或 Ctrl+滚轮确认后换色。
